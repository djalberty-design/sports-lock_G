### 1. URGENT BUG: Fix Page Freezing ("Page Unresponsive")
The site is freezing every 10–20 seconds for up to a minute (Chrome is throwing "Page Unresponsive" on `/today`). This is caused by running heavy combinatorial loops (calculating 2-leg, 3-leg, and 4-leg combos across the entire slate) on the main browser thread during re-renders or background polling.

**Apply these performance fixes immediately:**
1. **Candidate Pruning (Cap the Input Pool):** Do NOT calculate combinations across every single market on the board. Filter down to the **top 15–20 highest-edge legs** first, and generate combos ONLY from that curated pool. This drops the combination space from 3,000,000+ calculations down to a few hundred, eliminating browser lockups.
2. **Memoization & Web Worker:** Wrap the parlay evaluation engine in `useMemo` so it only recalculates when the live odds snapshot timestamp actually changes—never on routine component re-renders or user clicks.
3. **Throttle Data Polling:** Ensure background refetches do not trigger a full board re-simulation. Set stale-time to a minimum of 60 seconds and prevent unmounted component memory leaks.
