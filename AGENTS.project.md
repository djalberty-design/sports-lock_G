**AI Picks** (`/today`) is the desk that *tells the user what to wager*. Hidden object is latent game `G` + usage `U` + live state `S`. Seeded paths. Fair blends 0.5 sim / 0.3 pool / 0.2 market. Rank every ticket type — popular (ML / spread / total), player props, period markets, same-game, cross-game 2/3/4-leg parlays — by `ticketScore`. Displayed % is `calibratedChance`, clipped at 99%. The Call is a high-info single (`infoQuality ≥ 0.72`, process Ran, not live, not a parlay, not a period slice, not desk% more than 1 pt under the book with no +edge). Ribbon is 2- or 3-leg mains (56%/60% floors). Last-10 is EWMA of the live ESPN log **on every stat**, not a W-L sticker. Leftover four are live ESPN, never invented: opponent-adjusted defense, pitcher-vs-batter, minutes/usage, xG-style underlying. Process looks empty = Looked. Same inputs → same ranking (`DESK_VERSION` `2026.09.10-master-v6`). Combos are pruned to the top 15–20 highest-edge legs before enumeration. Ranking runs in a worker and only when posted odds actually change (60s stale). Mood: Safest (65% floor with highest-probability fallback) / Best Value / Pays more. The gold ribbon is The Call; the column is Best Value. Ticket count vs handle is a layer, never a copy-trade. Tap a ticket → `/ticket?id=` full algorithm + rules the desk ran. One screenshot CTA (camera **and** library, editable OCR).
